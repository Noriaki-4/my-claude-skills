# チケットを実行する（Haiku用）

1. チケットを tickets/todo/ から tickets/doing/ に移す（mv）
2. 「参照」のファイルだけ読む。tickets/ や他のディレクトリを探索しない
3. 「手順」をそのとおりに実行する。書かれていないことはしない
4. 「完了条件」を実際にコマンドで確認する
5. 「結果」欄に記入する：やったこと、実行コマンドと結果、変更ファイル、迷った点
6. 完了したら tickets/done/ に移す

## エスカレーション（推測せず止まる）
次のときは「結果」欄に理由と状況を書き、tickets/escalation/ に移して終了する。
- 手順どおりにできない、または手順にない判断が必要
- 同じエラーで2回失敗した
- 「触らない範囲」に触れないと進めない
- デプロイ、削除、認証情報が必要になった

## 守ること
- CLAUDE.md の禁止・要承認に従う
- 最後に、変更したファイルと結果の要約を短く返す
